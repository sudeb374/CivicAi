# CivicAI Frontend

This is the frontend foundation for the CivicAI application, built using React + Vite.

## Setup

1. Copy `.env.example` to `.env` (or let it be created/modified as needed)
2. Run `npm install`
3. Run `npm run dev` to start the development server

## Structure

- `src/components`: Reusable UI components
- `src/pages`: Application pages (Dashboard, Infrastructure, etc.)
- `src/services`: API service classes
- `src/hooks`: Custom React hooks
- `src/utils`: Helper functions

## Building for Production

Run `npm run build` to generate the production bundle.
